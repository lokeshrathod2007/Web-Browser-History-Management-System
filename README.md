Web Browser History Management System

A Browser History Management System built in C++ using the Stack data structure as part of DSA Case Study 6.

About the Project

When a person uses a web browser, they visit multiple websites. The browser maintains a history of recently visited pages. If the user clicks the Back button, the browser returns to the previously visited website.

This project simulates that behaviour using a Stack in C++.

DSA Concepts Used
Stack (LIFO - Last In First Out)
Push Operation (Visit a website)
Pop Operation (Go Back)
Peek Operation (View current website)
Stack Overflow handling (History full)
Stack Underflow handling (No previous page)
How to Compile and Run

g++ browser_history.cpp -o browser_history

./browser_history

Features
Store up to 10 website addresses
Visit a new website using Push
Go back to previous website using Pop
View current website using Peek
View complete browsing history
Handles case when history is full
Handles case when no previous page exists
